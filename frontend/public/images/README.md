# Fotografias reutilizadas

As fotografias foram recuperadas das URLs que já constavam no arquivo local `servidor_api_pets/data/pets.json`, da etapa anterior do usuário. Não foram obtidas do site de referência visual.

As cópias WebP permitem apresentar essas fotos sem depender de requisições externas durante a navegação. A associação das URLs originais aos arquivos está em `frontend/src/utils/petImages.js`. Fotos novas informadas pelo usuário continuam usando suas próprias URLs, e registros sem foto não recebem uma fotografia fictícia.
